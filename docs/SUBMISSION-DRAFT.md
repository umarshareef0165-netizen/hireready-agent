## Problem statement
Young people in Pakistan, including final-year computer science students in
Faisalabad, lack practical, job-ready AI skills, mentorship, and a clear
pathway to paid tech employment, so strong academic learning does not convert
into real tech jobs. Final-year students cannot show employers verifiable,
job-ready evidence: CVs list courses, not working projects; they do not know
which skills a real job description actually requires; and they have no
low-cost way to practise interviews or get structured feedback.

## Solution
An agentic coach (Planner → Extractor → GapAnalyser → PlanBuilder →
PortfolioBuilder → Interviewer/Feedback) that turns a CV + GitHub links + a
pasted job description into a skill-gap report, dated learning plan, verified
portfolio page, and mock-interview loop. A skill counts as "evidenced" only
when linked to a real project/task the student supplied.
