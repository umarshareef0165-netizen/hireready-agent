## Problem statement * (2–5 sentences)
Young people in Pakistan, including final-year computer science students in Faisalabad, lack practical, job-ready AI skills, mentorship, and a clear pathway to paid tech employment, so strong academic learning does not convert into real tech jobs. Final-year students cannot show employers verifiable, job-ready evidence: CVs list courses, not working projects; they do not know which skills a real job description actually requires; and they have no low-cost way to practise interviews or get structured feedback.

## What you built * (solution, key features, and how you used AgentFoundry)
An agentic coach (Planner → SkillExtractor → GapAnalyser → PlanBuilder → PortfolioBuilder → Interviewer/Feedback) that turns a CV + GitHub links + a pasted job description into a skill-gap report, a dated learning plan, a verified portfolio page, and a mock-interview loop. A skill counts as "evidenced" only when it is in the CV text AND linked to a real project/task the student supplied; otherwise it is "claimed, not evidenced" or "missing". Features: (1) ranked skill-gap report, one learning task per gap; (2) dated, bite-size learning plan with free official resources; (3) verified portfolio page + hiring-signal summary from supplied projects only; (4) mock interview for Python / ML / full-stack / agentic AI, scored against a visible rubric; (5) honest impact dashboard counting only real in-app actions.
